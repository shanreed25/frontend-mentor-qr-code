## Reflection

### How did using Figma designs as references affect your coding process?

> The design files help me have a visual reference as to what I needed to create

### What challenges did you encounter when aligning your code with the design specifications?

> I am kind of a prefectionist so I wanted to line everything up as close to the design as I could. To do this I used the Pixel Perfect Browser Extension

### How can the feedback and community resources on Frontend Mentor help you improve as a developer?

> It can allow you to learn by getting code reviews which can help you take the feedback and improve your code. The community resources can help you to see different ways to solve problems, that you would not figure out on your own
